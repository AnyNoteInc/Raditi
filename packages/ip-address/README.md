# @repo/ip-address

Лист репозитория: литералы IP-адресов и диапазоны, которые называют правила платформы (spec §19). `ipLiteral` приводит адрес к каноническому виду (без скобок, IPv6 сжат и в нижнем регистре, IPv4 в IPv6 — обычный IPv4; для имени — `undefined`), `isPrivateAddress` — RFC 1918 и ULA, `isLoopbackAddress` — `127.0.0.0/8` и `::1`. Нужен каждому приложению, которое проверяет, куда может идти соединение (`llm`, `mcp`, `runner`, `preview`, `core`). Вынесен из `core`, потому что домену нельзя `node:net`.

## Что читает

Ничего: чистые функции без ввода-вывода и без окружения.

## Команды

- `pnpm --filter @repo/ip-address typecheck`, `lint`, `test`. Сборки нет: Node исполняет исходники сам.

## Чего не должно достигать

Ничего из репозитория: пакет не импортирует ни один `@repo/*` (`LEAVES` в `.dependency-cruiser.cjs`) и не открывает сети. Импортировать его может любой пакет и любое приложение.
