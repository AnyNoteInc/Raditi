# Реестр находок

[← Оглавление ревью](README.md)

Все 184 находки восьми линз с итогом двух независимых проверок. «Подтверждено» — ни один проверяющий не отклонил; «спорно» — отклонил один из двух; «отклонено» — отклонили оба. Столбец «Задача» ведёт в [план работ](08-workplan.md): номер задачи этапа, «8.5» — ждёт решения владельца. Доказательства и точные правки — в разделе линзы. Столбец P — исходная оценка аудита; раздел линзы может понижать её по поправкам проверяющих.
