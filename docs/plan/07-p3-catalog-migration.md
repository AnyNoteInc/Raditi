# P3 B3: отключение старого каталога моделей

29.09.2026. Продолжение сессии Claude Code `Bootstrap`, после локальной подготовки B2.

## Изменения

Добавлена миграция `20260929120000_subscriptions_expand`: все провайдеры вида `api`, их модели и модели класса `service` выключаются. Строки каталога, цены и ссылки на них сохраняются. Миграция выполняется в одной транзакции; предыдущие миграции не менялись. Значение enum `service` и устаревшие поля остаются до миграции сужения следующего релиза.

У модели появилось поле `reserve_output_tokens`: целое число, обязательное, по умолчанию 32 000, с ограничением 1 024–131 072. Оно задаёт резерв при допуске вызова, а не лимит ответа провайдера. В B6 сиды добавят выключенные модели подписок без цен; профили Kimi должны явно задавать 32 768 по проекту P3.

Обычный `db:seed` теперь записывает только тарифы, правила оплаты за действие и драйверы. Создание прежних API-провайдеров, моделей и цен полностью удалено из сидов. Поэтому seed чистой базы не возвращает старый путь, а повторный seed существующей базы не меняет архивный каталог и историю цен. Ставки подписок не подставляются без утверждения владельца.

## Проверки

`pnpm gates` завершился с кодом 0 на Node 26.10 / pnpm 12.6, с `DATABASE_URL` отдельной PostgreSQL 17 и синтетическими данными: форматирование, переменные окружения, типы, lint, архитектура, тесты и production-сборка web/orchestrator. Неизменённые задачи могли использовать кэш Turborepo.

| `@repo/db` с PostgreSQL | 103/103, включая 7 проверок новой миграции |

13 пропусков относятся к интеграциям S3 и Docker; инфраструктурный пропуск — к проверке watchdog с отдельным окружением. PostgreSQL-тесты не пропущены. После проверки одноразовый контейнер PostgreSQL с временной файловой системой и отдельная рабочая копия удалены; весь код B3 перенесён в основную рабочую папку. Рабочая база проекта и её тома не изменялись. Общий журнал прогона сохранён локально в `/tmp/raditi-b3-main-gates.log`.

Спецификация и план уточнены: B3 оставляет каталог новой базы пустым, B6 добавляет выключенные модели подписок без цен. Это распределение оставшейся работы P3, без изменения требования утвердить ставки до выдачи ключей.
