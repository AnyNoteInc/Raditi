Снимок хода в `raditi-sessions`: `sessions/<sessionId>/turns/<NNNN>/{home.tar.zst, untracked.tar.zst, patch.diff, manifest.json}`; в манифесте `schemaVersion`, хеш считает хост, шифрует хост ключом данных Vault Transit. Восстановление в новом контейнере по фиксированным путям `/workspace/repo` и `/agent-home`. §8. *Проверено:* [отчёт и команды](02-p1-verification.md); запуск CLI с моделью и resume — P4/P5, lifecycle контейнеров — P2.
- [x] **P2. SandboxProvider и раннер.** Docker 29 + gVisor (`runsc`, systrap; на Mac — `runc`): dockerd от root, uid 10001, read-only rootfs, cap-drop ALL, no-new-privileges, лимиты. Контейнер на ход: `tini` + `sleep`, всё через exec, агент под обёрткой с группой процессов и файлом событий с оффсетами; `docker cp` и archive API не используем. Образ песочницы — по дайджесту в реестре Gitea. PoC — sandbox-providers/docker через dockerode к локальному сокету; пилот — роль `runner` на песочной ВМ (сам забирает ходы, без входящих портов, аренда с эпохой).
