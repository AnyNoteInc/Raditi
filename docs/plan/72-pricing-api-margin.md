# 72. Кредиты тарифов при марже 10 % на API (13.11.2026)

Запрос владельца от 13.11.2026: «давай возьмем текущие цены на сайте и посчитаем юнит экономику с маржинальностью в 10%, до скольки мы можем поднять количество кредитов на тарифах если будем пользоваться api а не подпиской». По расчёту (§3) он ответил: «давай сделаем так — старт — 200 кредитов, бизнес — 1000 кредитов, агенство — 2000 кредитов; скорректируй цену за тариф, чтобы была маржа 10%», а на предложенные цены — «исполняй».

| --- | --- | --- | --- | --- |

| Агентство | 10,00 | около 50 ₽ | 10,5 % | 83,7 ₽/$ |

Цена кредита на трёх тарифах почти одна: «Агентство» больше не продаёт кредит дешевле, его отличие — 15 сайтов.

## 3. Расчёт

Маржа — доля цены, которая остаётся после удержаний (ЮKassa 3,5 % с НДС 22 % на комиссию и НПД 4 % — 8,27 %) и всех переменных затрат, когда клиент выбрал всю квоту, а вся модель идёт через API Z.ai:

`цена = (кредиты × c + сайты × 16 ₽) / (1 − 0,0827 − 0,10)`.

Базовые затраты на списанный кредит c = 7,99 ₽:

- модель — 6,41 ₽: кредит полной работы — $0,055196 API (6,00 ₽ ÷ (83,6177 × 1,30), файл ставок `infra/billing/rates/2026-10-17-zai-api.json`), то есть 4,58 ₽ по курсу ЦБ 82,9803 на 13.11.2026; плюс 12 % — доплата сверх курса ЦБ за пополнение долларового баланса Z.ai из России (оценка 4–25 % по сторонним источникам) и 25 % бесплатной работы — упавших и остановленных проходов (допущение документов; замера после 10.11.2026 нет);
- вычисления — 1,34 ₽: 4,71 ₽ на действие (business.md §6) ÷ 3,52 кредита на действие — без минимума 5 (снят 10.11.2026) действие списывается в свою работу;
- веб-поиск Яндекса — 0,24 ₽: 0,488 ₽ за запрос, 0,5 запроса на кредит (замера нет); кредиты его не оплачивают;
- бэкапы — 16 ₽ на сайт (4 ГБ × 4 ₽ Timeweb S3).

Цена ровно для 10 % — 1 976 / 9 840 / 19 856 ₽; оптимистично (доплата 4 %, малые ВМ) — 1 680 / 8 361 / 16 898 ₽, в стрессе (доплата 25 %, бесплатной работы 58,8 % как в dev, 2,5 кредита на действие) — 2 885 / 14 384 / 28 943 ₽. Проверены 13.11.2026: курс ЦБ, цена API Z.ai ($1,40 / $0,26 / $4,40 за 1 млн, хранение кэша «временно бесплатно»), комиссия ЮKassa для самозанятых, НПД, цена Yandex Search API; расчёт прошёл ревью с трёх сторон.

## 4. Риски и открытое

- **10 % — нижняя граница для клиента, который выбрал всю квоту, а не маржа бизнеса.** У потолка НПД 10 % от 200 тыс. ₽ — 20 тыс. ₽ против постоянных расходов около 30 тыс. ₽ (сервер, сервисы, замена оттока); «Старту» 10 % — 199 ₽ в месяц, привлечение за 7 633 ₽ окупается 38 месяцев. Средний клиент тратит меньше квоты, но перенос остатка даёт выбрать всю квоту за два периода.
- **Курс.** Маржа 10 % уходит в ноль около 97 ₽/$ (+16 % к 13.11.2026).
- **Долг на API.** Бюджет ключа хода — весь свободный остаток пространства (`packages/billing/src/holds.ts`, `attemptCreditBudget`), шлюз сверяет деньги только по ключу, а предел на пространство (окна плана 71) действует только на вызовы плана (`apps/llm/src/accounting/gateway-store.ts`). На API до 8 параллельных проходов могут каждый потратить весь остаток и увести клиента в долг. До перевода production на `zai-api` нужен предел расхода на пространство — отдельная задача.
- **Хранение кэша Z.ai** бесплатно «на время»; кэш — 88–97 % ввода.
- Ветка #64 (`20261113150000_weekly_limits_only`, v1.34.0) убрала окна 5 часов раньше этой работы: миграция плана 72 идёт после неё, ждёт окон 5 часов NULL и меняет только недельные.
- ЦА6 владелец решил 13.11.2026 («продлеваем»).
- `docs/business.md` §6 и «Коротко», файл модели `docs/model/Raditi_unit_economics.xlsx` и `build_unit_economics.py` на тарифах 13.11.2026 не пересчитаны: в business.md стоят пометки, расчёт новых тарифов — `docs/research/2026-11-pricing/calc_api_margin.py`. Отдельная задача.
