# Чат → предпросмотр → /release

Составлен 17.10.2026 по запросу владельца: пользователь описывает изменение сайта в чате, проверяет результат на рабочей копии и командой `/release` выпускает новую версию на настоящий сайт; в чате по `/` открывается окно команд. Работа идёт в ветке `feat/chat-preview-release` (отдельное дерево `raditi-release`, от `b8f2412`): основное дерево в это время правит мастер подключения сайта ([план 39](39-site-connection-wizard.md)), с которым ветку предстоит слить. Вторая редакция того же дня — после состязательной проверки с трёх сторон (безопасность, восстановление, исполнимость): 41 замечание, приняты все, кроме тех, что названы в «Отвергнуто».

Этот файл — договор для всех срезов: имена таблиц, перечислений, очередей, портов, переменных и маршрутов ниже обязательны. Где решение меняет spec или правило CLAUDE.md, оно названо и войдёт в spec §20 (срез R13).

## Решения

Источник — запрос владельца от 17.10.2026 («О»), его ответ на вопрос о переменных («О-перем.»: «Агенту и предпросмотру, оба в сеть»); остальное — значения по умолчанию по указанию от 09.10.2026 («У»).

### Отвергнуто

- «Двигать `main` последним» (тег и `refs/releases/<id>` до установки, `main` — fast-forward после): владелец назвал порядок «опубликовать в `main` → тег → выкладка»; тот же результат («`main` равен установленному») держит инвариант revert-коммита Р27.
- «Перешифровать home снимка под новую голову после «Обновить»»: дороже и рискованнее флага `rebased`.
- «Проход без изменений → `awaiting_user`» при отсутствии кандидата: меняет оплату (вопросы стали бы бесплатными), владелец просил её не менять.
