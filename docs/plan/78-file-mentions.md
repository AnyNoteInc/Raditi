# План 78. Упоминание файла через «@»

Указание владельца от 14.11.2026 — «продолжай улучшать продукт», повторено 15.11.2026 («продолжай»). Следующая возможность из [перечня возможностей агентов](../research/2026-11-agent-features/README.md): упоминание файла через «@» (IM-01, у 32 продуктов) и папки (IM-02, у 21). Это самая частая из оставшихся возможностей, которых нет в Радити, и для неё не нужны ни новые внешние сервисы, ни новые таблицы.

Работа — в ветке `feat/file-mentions` (дерево `raditi-mention`, от `main` `158b1978`).

## Решения

Значения по умолчанию (указание от 09.10.2026); владелец их по существу не подтверждал.

- **У1.** В чате с кодом проекта `@` в начале поля или после пробела открывает над полем список «Файлы проекта». Буквы после `@` его сужают: сначала имена, которые с них начинаются, потом пути, потом остальные совпадения; не больше 8 строк. Стрелки выбирают, Enter или Tab вставляют, Escape закрывает. Адрес почты (`name@site.ru`) упоминанием не считается.
- **У2.** Список — файлы рабочей копии чата (`siteFiles.list` с `taskId`, то же, что во вкладке «Терминал»), а на «Новом чате» с проектом — файлы установленной версии сайта. Список читается при первом `@`, а не при открытии страницы. Пока `core` готовит список, в окне написано «Готовим список файлов…». Папки выводятся из путей файлов. В чате без проекта и в чате проекта без кода списка нет.
- **У3.** Выбор вставляет в слова `@<путь>` от корня репозитория: после файла ставится пробел, после папки — нет, её можно сузить дальше. Ничего не прикрепляется, слова уходят как написаны. Агенту в разделе «The files you may change» сказано, что `@` перед путём — файл или папка репозитория от его корня. Файл агент сначала читает, а если путь вне рабочего набора, говорит об этом клиенту.
- **У4.** Правило 1 не меняется: путь — часть слов клиента, которые и так идут модели. Список файлов web уже читает для «Терминала».
