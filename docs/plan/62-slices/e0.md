   * Gives an open folder to the platform. gVisor (runsc) answers EPERM to a fchmod right after a
   * fchown; a stat of the descriptor in between cures it, the cause is not confirmed. The stat
   * below is load-bearing, it is not a check. Measured: runsc release-20260921.0, not under runc.

  export async function adoptPlatformFolder(handle, gid) {
    await handle.chown(0, gid)
    await handle.stat()
    await handle.chmod(PLATFORM_FOLDER_MODE)

- *Договор.*

  ```ts
  /** What the gateway decides for every cookie of the site: the cabinet's frame is cross-site. */
  const GATEWAY_COOKIE_ATTRIBUTE = /^\s*(domain|secure|samesite|partitioned)\s*(=|$)/i

  /**
   * A Set-Cookie of the site as the cabinet's frame keeps it; null — it names the gateway's cookie.
   * A browser drops any other cookie of a cross-site frame on write, silently, and WebKit keeps
   * only a partitioned one. `SameSite` is replaced, not left: `Lax; Secure; Partitioned` is dropped
   * too. No condition on the request, the tab or the stack: an answer to a fetch sets cookies as
   * well, and in a tab a partitioned cookie is keyed by its own site.
   */
  export function siteSetCookie(line: string): string | null {
    const [pair = '', ...attributes] = line.split(';')
    const at = pair.indexOf('=')
    const name = (at < 0 ? pair : pair.slice(0, at)).trim()
    if (name === '' || isGatewayCookieName(name)) return null
    const kept = attributes.filter((attribute) => !GATEWAY_COOKIE_ATTRIBUTE.test(attribute))
    return [pair, ...kept, ' Secure', ' SameSite=None', ' Partitioned'].join(';')
  }
  ```

## Расхождения с проектом

Записи ниже писались по первой редакции проекта. В `62-site-stacks.md` уже стоят Р1 (Т37), Р3 и Р4 (Т57), Р5 (§5.1), Р7 (§5.3), Р9 (Т33): там они остаются как довод, спорить с проектом больше не о чем.

**Р1. Дословное исполнение отнимет `wp_rest` на весь первый ход и у сайта с плагином: это регрессия WordPress, которой проект не хотел. Договор Э0е: `undefined` остаётся открытым, а проверка `content_update` на вызове отказывает словами. Цена: сайт из мастера в первом ходе видит инструмент и получает отказ, со второго не видит. То же для `site_info`: `null` до первой сборки, а не пустой список. Как узнать такой сайт — значение вопроса Он21, что ему говорить — вопрос 30: инструкции Э7.5 уже в первом ходе инструмента не называют и ведут агента по правилу Т36.

**Р2. §5.2, строка 5: место правки.** Регулярное выражение `scrub_secrets` лежит не в `mysql-copier`, а в `packages/site-connections/src/database-copy/nested-secrets.ts:14-15`. Договор Э0ж правит там.
