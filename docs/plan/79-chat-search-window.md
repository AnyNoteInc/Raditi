# План 79. Окно поиска чатов, поле поиска и курсор нового чата

Запрос владельца от 15.11.2026 после выпуска плана 77: «на картинке в архиве верхняя рамка залезает; когда я нажимаю на иконку поиска — открывается диалоговое окно поиска, а не как сейчас появление просто поиска в чатах, в поле ввода две кнопки очистить, убери дефолтную; когда открывается новый чат, курсор по умолчанию должен ставиться в строку ввода».

Работа — в ветке `feat/chat-search-dialog` (дерево `raditi-search`, от `main`).

## Решения

- **П1.** Лупа в шапке колонки чатов открывает окно «Поиск чатов» (`search-dialog.tsx`); заменяет Р2 плана 77, по которому над списком появлялось поле. В окне поле «Найти чат», под ним — до 20 недавних чатов, закреплённые первыми, а когда слова введены и прошло 300 мс — найденные `task.search`: по названиям и словам клиента, в том числе в архиве, с пометкой «в архиве». Выбор чата открывает его и закрывает окно. Значения по умолчанию: недавние чаты в пустом окне, пометка архива.
- **П2.** Поле поиска одно на оба окна (`chat-search-field.tsx`): у него свой крестик «Очистить поиск», который виден только над словами. Крестик браузера у поля `type="search"` скрыт.
- **П3.** Рамка фокуса поля рисуется внутри него (`outline-offset: -2px`), поэтому окно «Архив чатов» и окно поиска не срезают её верх.
- **П4.** На «Новом чате» курсор стоит в поле, как только экран открылся.
