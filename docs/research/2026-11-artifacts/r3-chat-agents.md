## Главное

1. **Слово «артефакт» в 2026 году закрепилось как «результат задачи, отдельный от ответа».** Perplexity прямо определяет: «An artifact is a file or link that Computer creates for you during a task. The answer in your session explains what Computer did; the artifact is the result you open, download, share, and keep working on» ([Perplexity, 28.10.2026](https://www.perplexity.ai/help-center/en/articles/2026102801-what-are-artifacts)). Manus держит «Library» и API `artifact.list` с десятью категориями ([Manus API](https://open.manus.ai/docs/v2/artifacts)), MiniMax — «Assets» (11.02.2026), Grok — страницу «Library» (05.09.2026). У Mistral рабочая поверхность называется Canvas, у Genspark — canvas проекта, у Kimi — превью-панель и Workspace, у Qwen и Z.ai — «Artifacts».
2. **Рабочий артефакт и публикация — разные сущности почти у всех.** Perplexity: превью сайта видно только владельцу, «Publishing and visibility are separate» ([Perplexity, 06.10.2026](https://www.perplexity.ai/help-center/en/articles/20260711-publishing-your-website-to-the-web)). Kimi Build: «before publishing, it is preview-only», Unpublish сохраняет код и данные ([Kimi](https://www.kimi.com/en/help/websites/websites-overview)). Genspark: Design (холст) → «Build it» → проект Genspark Code → «Publish to Genspark Hosting», передача «one-way» ([Genspark Design](https://www.genspark.ai/helpcenter/genspark-design)). Qwen и Z.ai: превью артефакта в чате против Deploy (у Qwen — и Undeploy с повторным развёртыванием). Исключение — Mistral: отдельного «сайта» нет, есть ссылки на просмотр.
3. **Одновременной многокурсорной правки артефакта людьми не документирует ни один из десяти продуктов.** Совместность реализована иначе: общий чат-задача, где все пишут агенту (Manus Collab), роли Viewer/Editor с точками сохранения и «конфликтной» точкой (Genspark), общий контекст проекта и несколько агентов в нём (Perplexity Projects и Teammates, Kimi Claw Group Chat), несколько задач на одном сайте с автослиянием и общей историей версий (Manus «Edit in New Task»).
4. **Самое ценное для «нескольких агентов на одном артефакте» — Manus «Edit in New Task»:** «All tasks that edit the project share one version history… Before each saved version, Manus places its changes on top of the newest version. If two tasks change the same lines, the agent resolves the conflict… Each saved version records the task that created it», в превью — «You're viewing an older version… sync to update this preview», но «The database is shared and has no conflict protection» ([Manus](https://manus.im/docs/website-builder/edit-in-new-task)).
5. **Пометки на артефакте, собранные пакетом и отправленные агенту одним ходом, — общий приём:** Perplexity Edit (Selection tool Text/Element/Area → Edits panel → «Submit 3 edits»), Genspark Draw (Edit queue → «Send N edits»), Mistral Slides (комментарии к элементам, по одному или пакетом), Kimi Build/PPT/Design (обвести, стрелка, кисть, комментарий к элементу), MiniMax Infinite Canvas (выделить область картинки или элемент HTML), Manus Design View (Mark tool, на телефоне — долгое нажатие и голос).
6. **Версии — повсеместно, но по-разному:** новая версия на каждую правку агента (Perplexity v3, Kimi PPT/Design, Genspark Save Points), ручные правки склеиваются (Genspark: точка сохранения не чаще раза в 5 минут, подряд идущие правки одного человека сворачиваются), есть «вид изменений» (Mistral change-tracking view). Встречаются опасные решения: откат в Genspark AI Docs «removes every Save Point after the one you chose and clears the conversation too».
7. **Шеринг — двухосевой диалог «кто» и «что».** «Кто»: приглашённые люди (по почте) с ролью, организация, «Anyone with the link», запрос доступа (Perplexity). «Что»: Genspark разводит «Just the slides» и «The whole process»; Mistral, Qwen, Genspark «Share this file» подчёркивают, что чат не передаётся. Живая ссылка или снимок различаются: Mistral Slides — снимок («the link still shows the earlier version… click Update link»), Genspark файл — живая («The link always shows the latest version of this file»).
8. **Изоляция рендера — отдельные регистрируемые домены у опубликованного:** `pplx.app` (Perplexity), `*.ok.kimi.link` (Kimi), `*.vip.gensparksite.com` (Genspark); у Z.ai артефакт — в iframe с `sandbox="allow-scripts allow-forms allow-popups allow-popups-to-escape-sandbox"` (бандл prod-fe-1.2.20). Grok в общих чатах делает интерактивные карточки только для просмотра и без коннекторов владельца (03.10.2026).
9. **Агентские API артефактов редки.** Документированы: Mistral Studio — Canvas как выход workflow и `wait_for_input(CanvasInput)`, когда workflow ждёт ручной правки Canvas человеком; Manus API v2 — `artifact.list`, `share_visibility`, выдача слайдов в PPTX и Markdown в PDF/DOCX; Z.ai Slide/Poster Agent API — поток операций над страницами (`tool_name` вроде `insert_page`, `position`, HTML страницы); MiniMax Mini Apps — приложение само отдаёт агенту MCP-инструменты и вызывает агента, а текст в поле ввода кладёт только с подтверждением пользователя.
10. **DeepSeek артефактов в потребительском чате не имеет** (по официальным новостям и открытому `chat-demo`, повторяющему приложение); у открытого DeepSeek Harness (13.08.2026) есть подсистема «deliverables» с инструментом `present`, а «канвасы» — сторонние плагины.

## Продукты

### 1. Perplexity (Computer, Artifacts, Projects; бывшие Labs, Pages, Spaces)

1. **Понятие.** «Artifacts» в Perplexity Computer — агенте, который «does your work»: «file or link that Computer creates for you during a task»; каждый артефакт есть в сессии и на странице Artifacts ([What are Artifacts?, 28.10.2026](https://www.perplexity.ai/help-center/en/articles/2026102801-what-are-artifacts); [What is Computer?, 17.11.2026](https://www.perplexity.ai/help-center/en/articles/13837784-what-is-computer)). Предшественники: Labs (29.05.2025) — «Assets» под запросом и мини-приложения «directly below your query» ([блог, 29.05.2025](https://www.perplexity.ai/hub/blog/introducing-perplexity-labs)); затем режим «Create files and apps» и «Creating assets» ([01.09.2026](https://www.perplexity.ai/help-center/en/articles/12528830-creating-assets-with-perplexity-overview)); переименование Labs → «Create files and apps» и Spaces → Projects подтверждено вторичным источником ([horadecodar](https://horadecodar.com.br/perplexity-labs/)) и справкой: «Create files and apps» назван режимом в статье «Creating assets», а статья 10352961, прежде «What are Spaces?», теперь называется «What are Projects?». Pages: «The "Create page" feature is temporarily retired, and "Convert to Page" feature will be returning shortly» ([14.09.2026](https://www.perplexity.ai/help-center/en/articles/10352968-perplexity-pages)).
2. **Типы.** PDF и DOCX; PPTX «with charts and speaker notes»; XLSX «with formulas, formatting, and multiple sheets»; картинки; короткие видео и аудио; «interactive charts and diagrams shown in the session»; «Websites and apps: web pages published to a shareable pplx.app link»; «Links: items Computer creates in a connected app, such as a Google Doc». Загруженный файл, который Computer правит, сохраняется новым артефактом — оригинал не меняется.
3. **Где.** Превью — в боковой панели, «expand» на весь экран («Creating assets»); страница Artifacts: «Search artifacts», вкладки All / Created by you / Uploaded by you / Shared with you, фильтр по типу. На телефоне Edit недоступен.
4. **Кто правит.** Агент. Пользователь — «Edit»: открыть артефакт → Edit → Selection tool: Text, Element («part of an app or web page») или Area (обвести) → описать правку → повторить; правки копятся в Edits panel → «Submit 3 edits» одним пакетом. Доступно для документов, PDF, презентаций, таблиц, графиков, отчётов и приложений «in sessions you started»; не для картинок, видео, аудио и не на телефоне. Ручного редактора нет: «you will need to download the file and use compatible software» («Creating assets»).
5. **Версии.** «Each time Computer revises an artifact, it saves a new version and keeps the earlier ones»; номер версии у имени (v3) открывает «Select version» с галочкой текущей; можно сказать «Go back to the previous version of the deck and only change the chart»; удалить одну версию или все. Сравнения версий не описано.
6. **Совместная работа.** Projects: роли Owner / Can edit / Can view; до 5 участников (9 999, если владелец в организации или проверенный учащийся); «Request edit access» с одобрением владельца ([What are Projects?, 13.11.2026](https://www.perplexity.ai/help-center/en/articles/10352961-what-are-projects)). Teammates (исследовательская версия для Max): у каждого агента своя роль, рабочий стол и браузер; «Teammates in the same Project share context, files, and instructions… They can message each other when new information arrives» ([18.11.2026](https://www.perplexity.ai/help-center/en/articles/2026102601-perplexity-teammates)). Одновременная правка одного артефакта людьми — не описана.
7. **Шеринг.** По умолчанию артефакт наследует доступ сессии. Варианты General access: «Access is inherited from session», «Only people with access can view», «Anyone in (org) with access can view» (Enterprise), «Anyone with the link can view»; плюс приглашение конкретных людей; роль приглашённых — просмотр. Отозвать — вернуть «Only people with access». Администратор Enterprise может выключить публичный вариант. Сессии: Private / Anyone with the link / Anyone in my org ([What is a Session?](https://www.perplexity.ai/help-center/en/articles/10354769-what-is-a-thread)). Projects «cannot be made publicly queryable».
8. **Привязка.** К сессии и странице Artifacts. В проекте артефакт видят участники; «Make private» убирает доступ; «save it to Project files» делает его постоянной частью контекста проекта; «Convert session to project» переносит файлы и артефакты; Computer находит артефакт по просьбе («Find the budget spreadsheet you made me last week»).
9. **Агентская сторона.** Публичного API артефактов не нашёл (не подтверждено). Computer работает с плагинами (коннекторы и навыки), в справке есть раздел о локальных и удалённых MCP-серверах ([индекс справки](https://www.perplexity.ai/help-center/_llms/en/help-center.txt)).
10. **Экспорт.** Download — редактируемые .pptx, .docx, .xlsx; «Save to Drive as Google Doc / Sheet / Slides» (нужен подключённый Google Drive); сайты — pplx.app или «Publish with Vercel» (свой домен через коннектор Vercel).
11. **Безопасность.** Сайты — на отдельном домене `pplx.app`; приватную pplx.app-ссылку чужой не откроет, но может запросить доступ по почте. CSP и песочница не описаны.
12. **Лимиты и цена.** Computer — на платных планах; Max — 10 000 кредитов в месяц, у Pro ежемесячных кредитов нет (разовый бонус 4 000); артефакты расходуют кредиты задачи, «Larger or more complex artifacts… generally use more». Проект: до 10 000 файлов, 5 ГБ, 100 МБ на файл; инструкции — до 8 000 знаков.
13. **Рабочее и опубликованное.** Разведено жёстко. Артефакт — файл или ссылка с версиями и доступом. Сайт: «starts in a preview, visible only to you»; Publish → `pplx.app`; повторная публикация — в тот же адрес; видимость (private / organization / specific people / public) отдельна от факта публикации; Unpublish; администратор может запретить публичную публикацию — тогда пропадает и Vercel ([06.10.2026](https://www.perplexity.ai/help-center/en/articles/20260711-publishing-your-website-to-the-web)). Сайты потребителей публичны по умолчанию, сайты организаций — только для организации.

Путь пользователя (сайт): описать задачу Computer → превью в сессии → Publish (или Publish with Vercel) → Published → General access → при правке попросить Computer — он перепубликует тот же адрес → Unpublish.

### 2. Mistral Vibe (бывший Le Chat): Canvas, Mini apps, Slides, Spreadsheets

1. **Понятие.** Le Chat переименован в Vibe 28.05.2026: «Le Chat is now Vibe—one agent and one licence across work and code», режим Chat скоро уберут ([Mistral, 28.05.2026](https://mistral.ai/news/vibe-agent); [heise](https://heise.de/-11311685), вторичный). «Canvas is the built-in editor where Work produces, previews, and refines outputs» ([Files and Canvas](https://docs.mistral.ai/vibe/work/web/files-and-canvas)).
2. **Типы.** Текст, данные (таблица из CSV), код, презентации (Marp в Canvas; настоящие .pptx — «Slides», только платно), «Mini apps: self-contained React applications that run directly in the Canvas panel» ([Mini apps](https://docs.mistral.ai/vibe/work/web/mini-apps)), «Spreadsheets» с листами и формулами (платно) ([Spreadsheets](https://docs.mistral.ai/vibe/work/web/spreadsheets)). Режим превью рендерит «HTML, React components, Mermaid diagrams… and Marp presentations». Для workflow Studio типы Canvas: `text/markdown`, `text/html`, `image/svg+xml`, `slides`, `react`, `code`, `mermaid` ([Studio Canvas](https://docs.mistral.ai/studio/workflows/interacting-with-workflows/conversational_workflows/canvas)).
3. **Где.** Включение: «+» или «/» → Tools → Canvas; дальше Canvas открывается сам, «when Work determines it would be useful», или по `/canvas` и словам «open in Canvas». «Multiple Canvases: open several Canvases in one chat. Each one appears as a tab». Mini app сначала появляется превью в ленте, «Expand» открывает боковой Canvas. Слайды: Fullscreen и Present. На телефоне редактор слайдов не открывается — только скачать ([Slides overview](https://docs.mistral.ai/vibe/work/web/slides/overview)).
4. **Кто правит.** Пользователь прямо: «click anywhere to edit text, code, or data by hand». ИИ по выделению: «select a passage to reveal the Ask Work field… Work applies the change to the selection only»; «Quick actions: click the sparkle icon… translate, optimize, or visualize». Mini app: «Preview (eye icon)» / «Code (<> icon)» со списком файлов, правка исходников руками. Слайды: просьба в чате; «Comment on slide elements» — Comment → клик или рамка по элементам → инструкция → «Send comment» (Cmd+Enter) сразу или «Add comment to batch» (Enter), пакет уходит с сообщением; ручной редактор: текст, шрифты, картинки, фигуры, линии, таблицы, фон, порядок слайдов, автосохранение ([Edit slides](https://docs.mistral.ai/vibe/work/web/slides/edit-slides)). Таблицы: клик по ячейке, формулы, Edit/View.
5. **Версии.** «Version control: use the navigation arrows to move between versions. Toggle the change-tracking view to see exactly what changed. Restore any previous version at any time». В слайдах undo/redo — для недавних ручных правок, дальше — версии Canvas: «each time Work changes the presentation, Canvas keeps the earlier version… click Restore».
6. **Совместная работа.** Совместной правки нет; Team — «a shared workspace with admin controls and more storage» (новость 28.05.2026).
7. **Шеринг.** Canvas: «Share: distribute the full chat, including Canvas content»; «Copy: transfer raw Canvas content». Mini app: Share → «Link accessible to anyone» → Copy link или кнопки email, X, LinkedIn, Reddit, WhatsApp; «Your chat messages aren't shared»; снять — тот же тумблер. Таблица — так же. Слайды: «Link accessible to organization members» (или «Link accessible to anyone», если администратор включил «Allow public sharing of chats content»); «If you edit the deck after sharing it, the link still shows the earlier version. ## Как продукты разводят рабочий артефакт и публикацию

- **Три состояния, а не два.** Рабочий объект (версии, правки, доступ участникам) → ссылка на просмотр (без чата, с ролью) → публикация (отдельный адрес, отдельная видимость, снятие). Perplexity, Kimi, Manus, Genspark, Qwen, Z.ai держат все три; Mistral — первые два.
- **Публикация — снимок или «последняя версия»?** Perplexity и Kimi перепубликуют в тот же адрес только по действию («Ask Computer to update… it re-publishes», Kimi «Update»); Mistral слайды — снимок с «Update link»; Genspark файл — всегда последняя версия.
- **Снятие сохраняет работу:** Kimi «Unpublish… code and data are retained», Genspark «Unpublish removes the hosted site. It doesn't delete your project files», Qwen «you can always redeploy».
- **Связь с чатом.** Qwen и Kimi гасят ссылки при удалении чата; у Perplexity, Manus и MiniMax артефакт живёт в библиотеке пользователя независимо от чата.

## Совместная работа и несколько агентов: что реально существует

- **Люди + один агент в одной задаче:** Manus Collab — общий тред, каждый пишет агенту, платит владелец, приглашает только владелец, входы песочницы сбрасываются.
- **Несколько агентов (задач) + один объект:** Manus Edit in New Task — общая история версий, автослияние кода, конфликты решает агент, версия помнит задачу-автора, баннер «устаревшее превью — Sync», данные без защиты.
- **Несколько агентов в одном контексте:** Perplexity Teammates (общий контекст проекта, пишут друг другу), Kimi Claw Group Chat (Conductor и Threads, у каждого бота своя ветка контекста), Genspark GenTeam (задача — один исполнитель за раз), MiniMax BYOB (журнал только на дописывание, предложение отдельно от совершения).
- **Люди + люди на одном артефакте:** Genspark Docs и Design — роли Editor, конфликт агента и ручной правки → отдельная точка сохранения; курсоров и присутствия никто не описывает.
- **Человек правит, агент ждёт:** Mistral Studio `wait_for_input(CanvasInput)`; MiniMax `message.append` — страница кладёт текст в поле ввода, отправляет человек.

### Модель: артефакт ≠ страница ≠ файл

1. **Артефакт** — рабочий объект: владелец (пользователь), пространство, необязательный `projectId`, вид, заголовок, текущая версия, участники с ролями, комментарии. **Страница** — публикация конкретной версии артефакта через уже существующий конвейер страниц. **Файл** — выгрузка (PDF, DOCX, PPTX, PNG, ZIP) — как Perplexity (артефакт и pplx.app), Kimi (превью и Publish), Genspark (Design → Code → Hosting).
2. **Артефакт не принадлежит чату.** Он живёт в библиотеке пользователя или проекта, чаты на него ссылаются (как страницы плана 73, которые с чатами уже не связаны). Удаление чата не гасит артефакт и его ссылки (в отличие от Kimi и Qwen).
3. **Личный или проектный.** Личный видит только владелец и приглашённые; проектный — участники проекта (когда в проектах появятся участники) плюс приглашённые. Действия «Сделать личным» и «Добавить в контекст проекта» (Perplexity «Make private», «save to Project files» → у Радити `project_files`), «Перенести в проект».

### Типы артефактов (что добавить; в скобках — у кого подсмотрено)

1. Текст (`.md`) с разделами — есть как документ; добавить ручную правку и правку выделенного (Mistral Ask Work, Genspark AI Edit).
2. Страница HTML — есть; добавить «вид исходника» и правку текста элемента по клику (Kimi Preview/Code, Manus Quick Style Controls).
3. **Холст из фреймов** для дизайна сайта: несколько HTML-фреймов рядом (варианты главной, ширины 390/768/1440), заметки, «Варианты» и «Ползунки», которые агент сам создаёт под макет (MiniMax Infinite Canvas и Vary, Genspark Design Tweaks, Kimi Design), «Сделать страницей» — передача фрейма в публикацию (Genspark «Build it»).
4. **Слайды** как HTML-страницы, по одной на слайд, с операциями «вставить / заменить / удалить по позиции» (Z.ai Slide Agent API) и показом; PDF — печатью Chromium, PPTX — позже (Mistral, Kimi, Genspark, Z.ai «Converting HTML pages to PPTX»).
5. **Таблица** с листами и формулами, правка ячеек, «отдать диапазон агенту» (Mistral Spreadsheets, Genspark AI Sheets «Send to Chat») — прайс, смета, сравнение конкурентов.
6. **Отчёт или дашборд** — страница с графиками из данных клиента (Perplexity charts, Manus Data Analysis).
7. **Схема** Mermaid → SVG: карта сайта, воронка, процесс (Mistral Preview, Grok Mermaid edit).
8. **Мини-приложение со своим хранилищем** (калькулятор цены, квиз, форма заявки, чек-лист) и кнопкой «спросить агента», которая кладёт текст в поле ввода, а отправляет человек (MiniMax Mini Apps `message.append`, Mistral mini apps).
9. **Постер или набор карточек для соцсетей** на холсте заданного размера (Kimi Design, Genspark Poster) — без нейросетевых картинок, вёрсткой и SVG.
10. **Интеллект-карта** (Kimi Deep Research mind map).
11. **Бренд-набор или дизайн-система** — цвета, шрифты, логотип, кнопки; применяется к новым артефактам (Genspark Design System, Kimi «保存为自定义风格», Z.ai «Save as template»).
12. Позже: доска-мудборд с картинками и страницами (MiniMax), прототип со связанными экранами (Genspark Prototype), мини-CRM (Genspark AgentBase).

### Панель справа и раздел «Артефакты»

1. Вкладка «Артефакты» в «Инструментах»: открытые артефакты — вкладками (Mistral «Multiple Canvases… Each one appears as a tab»), переключатель «Вид / Код», «На весь экран», «Телефон / компьютер» (Kimi, Manus).
2. Раздел кабинета «Артефакты»: «Все / Мои / Загруженные / Доступные мне», фильтр по виду, поиск (Perplexity Artifacts page; Manus Library; MiniMax Assets; Grok Library); с карточки — «Открыть в чате», «Продолжить в новом чате» (Manus «Edit in new task»; MiniMax «attach files to new tasks»).
3. Упоминание артефакта через `@` в поле чата (как файлы плана 78) — IM-25.
4. Потоковое заполнение: скелет и части появляются по мере записи (Genspark — страница за страницей, MiniMax PPT Live Preview); у Радити уже есть разделы документа, видимые сразу после записи (план 74).

### Правка, пометки, версии, конфликты

1. **Пометки пакетом:** выделить текст, элемент или область → комментарий → очередь пометок над полем → «Отправить N правок» одним ходом (Perplexity Edits panel, Genspark Draw, Mistral batch, Kimi Build). Пометки хранить на сервере, а не в браузере (у Genspark Design булавки «never leave the browser» — для совместной работы бесполезно); пометка — тред, агент отвечает в нём и закрывает (закрывает OR-146).
2. **Правка выделенного без перегенерации:** «applies the change to the selection only» (Mistral).
3. **Ручная правка** — бесплатно, с автосохранением (Genspark ~0,5–1 с).
4. **Версии:** каждая правка агента — версия с автором (пользователь, чат, ход), с отметкой «что изменилось» (Genspark — какие слайды, Manus — какая задача); ручные правки одного человека склеивать (Genspark — не чаще раза в 5 минут); «вид изменений» между версиями (Mistral change-tracking view); восстановление — новой версией, не удаляя последующие (не как откат Genspark AI Docs).
5. **Конфликты:** `expectedVersion` на каждую запись (как у `page_edit`); при расхождении инструмент возвращает текущую версию и разницу, агент переносит свою правку поверх новой (Manus); правка человека во время записи агента сохраняется отдельной версией «конфликт», а не теряется (Genspark); баннер «Вы смотрите старую версию — обновить» (Manus Sync).
6. **Применение сразу, а не в конце хода.** У страниц резерв применяется в конце хода; для совместной работы правка артефакта должна появляться у всех через мгновение — как разделы документа в плане 74.

### Несколько агентов

1. Несколько чатов одного пользователя правят один артефакт: общая история версий, у каждой версии — чат и ход; в выдаче инструмента — «с момента вашего чтения изменилось: …» (Manus «Changes from other tasks are intended»).
2. Агент, пишущий часть (раздел, слайд, фрейм), показывается присутствием «Агент чата „…“ пишет раздел 3»; человек может править другую часть; одну часть одновременно — по правилу конфликта выше.
3. Внешние действия (публикация, приглашение людей, отправка по почте) — только предложением, которое подтверждает человек: принцип «предложение отдельно от совершения» (MiniMax BYOB «commit gateway»; Manus «Only the task owner can invite»; MiniMax `message.append`).
4. Данные артефакта-приложения — с версиями строк или транзакциями: у Manus общая база «has no conflict protection».

### Шеринг

1. Диалог «Поделиться»: люди (по почте или аккаунту) с ролью «читатель / комментатор / редактор» — роль комментатора нужна (у Genspark её нет); общий доступ: «только приглашённые» (по умолчанию) / «все, у кого ссылка»; «что видно»: только артефакт или артефакт с ходом работы (Genspark «Just the slides» / «The whole process»; Mistral и Qwen — «чат не передаётся»).
2. Запрос доступа по ссылке и одобрение владельцем (Perplexity, Kimi-группа).
3. Срок ссылки — по желанию (у Genspark срока нет — риск; у Qwen есть); отзыв — сменой доступа, мгновенно.
4. Явно показать, живая ссылка или снимок: ссылка на артефакт — живая (последняя версия, по правам); публикация страницы — снимок версии v1, v2 (как сейчас).
5. Приглашённый читатель — «Сделать копию себе» (Genspark Remix, MiniMax Gallery Remix, Z.ai remix): копия содержимого без секретов, переменных и данных владельца.
6. Кто платит, когда приглашённый редактор просит агента: решить явно (Manus Collab — владелец; Genspark GenTeam — создатель агента).

### MCP-инструменты (черновик семейства `artifacts`)

Схема как у `pages`: префикс `raditi_`, `expectedVersion` на запись, ответ без значений секретов. Отличие: запись применяется сразу и создаёт версию.

| Инструмент | Аргументы | Что делает |
|---|---|---|
| `raditi_artifact_list` | `scope` (мои, проект, доступные), `kind?`, `query?`, `limit` | список с версией, автором последней правки, числом открытых пометок |
| `raditi_artifact_read` | `artifactId`, `version?`, `part?` | содержимое целиком или части (раздел, слайд, фрейм, лист), оглавление частей |
| `raditi_artifact_create` | `kind`, `title`, `projectId?`, `content` или `parts[]` | новый артефакт v1, открывается справа |
| `raditi_artifact_edit` | `artifactId`, `expectedVersion`, `edits[1..20]: {old, new, all?}` | замена фрагментов (как `page_edit`); конфликт → текущая версия и разница |
| `raditi_artifact_parts` | `artifactId`, `expectedVersion`, `ops[]: {op: insert/replace/delete/move, partId?, position?, content?}` | операции над частями — слайды, фреймы, разделы, листы (как Z.ai `insert_page` с `position`) |
| `raditi_artifact_comments` / `_comment_reply` | `artifactId`, `status?` / `commentId`, `text`, `resolve?` | читать пометки и отвечать в треде, закрывать |
| `raditi_artifact_versions` / `_restore` | `artifactId` / `version`, `expectedVersion` | список версий с авторами; восстановление — новой версией |
| `raditi_artifact_publish` | `artifactId`, `version`, адрес | публикация версии через конвейер страниц |
| `raditi_artifact_share_propose` | `artifactId`, `people[]`, `role`, `link?` | только карточка-предложение; доступ выдаёт человек |

### Безопасность рендера

1. Опубликованное и исполняемое — на отдельном регистрируемом домене (pplx.app, ok.kimi.link, gensparksite.com); у Радити такое решение уже принималось для предпросмотров (`raditi-preview.ru`).
2. Песочница фрейма без `allow-same-origin` (как у страниц сейчас) и без `allow-popups-to-escape-sandbox` (у Z.ai он есть).
3. В общей ссылке интерактив не получает ни коннекторов, ни навыков, ни кредитов владельца (Grok, 03.10.2026); переменные пространства и входы браузера владельца не становятся доступны приглашённым (Manus сбрасывает входы песочницы при подключении участника).

### Экспорт, телефон, деньги

1. Экспорт: PDF (печать Chromium), DOCX и XLSX (уже умеет песочница), PPTX — позже, ZIP исходников (Mistral mini apps, Genspark Design, Manus Code Control).
2. Телефон: просмотр, пометки долгим нажатием и голосом (Manus Design View; у Радити есть диктовка SpeechKit), правка частей — с компьютера (Perplexity и Mistral на телефоне правку не дают).
3. Деньги: правка агентом — кредиты; ручные правки, просмотр, шеринг — бесплатно (Genspark «Manual edits cost nothing»; AI Drive — файловые действия без кредитов).

## Чего избегать

1. **Публичная ссылка на весь проект с исходниками и историей версий** (Genspark Design: «opens the design, its source files and its version history to anyone… with no sign-in», «There's no per-link expiry»).
2. **Пометки, живущие только в браузере** (Genspark Design pins) — второй участник и агент их не видят.
3. **Откат, который стирает последующие версии и разговор** (Genspark AI Docs).
4. **Неявный снимок при шеринге** (Mistral Slides: ссылка показывает старую версию до «Update link») — либо явно «снимок», либо живая ссылка.
5. **Общие данные без защиты от конфликтов** при нескольких агентах (Manus: «The database is shared and has no conflict protection»).
6. **Режимы и формат, фиксируемые навсегда при создании** (Genspark Slides: «All three lock with the project»; AI Docs: «The format is locked once a document has content»).
7. **Ссылки, умирающие вместе с чатом** (Kimi, Qwen).
8. **«Открыть в Google» без обратной синхронизации** как основной путь правки (Mistral, Perplexity) — две копии расходятся.
9. **Общий агент с ресурсами владельца** для других людей (Z.ai: «Others using the agent may consume your sandbox resources»).
10. **Один файл за ход** (Kimi Agent) и прочие произвольные ограничения формата сдачи.
11. **Правка, недоступная в части режимов** без объяснения (Genspark Creative: «Edit is switched off»).
12. **Экспорт базовых форматов только за деньги** (Genspark: Free «can't take a file out in any format») — отпугивает при первом знакомстве.

## Не подтверждено и пробелы

- Perplexity: CSP и изоляция pplx.app; API артефактов; сравнение версий.
- Mistral: изоляция mini app и домен ссылки; живая ли ссылка mini app (для слайдов — снимок).
- Grok: доступен ли сейчас Grok Studio; флаги `disable_chat_canvas`, `grok_web_get_artifact_by_version_id`, `app_builder_warn_on_public_deploy` — только конфигурация анонимной сессии.
- Qwen Chat и чат Z.ai: только строки интерфейса; часть строк 1.2.12 («Deployments Management», «Save as template», «Code View/Live Preview») в загруженных чанках 1.2.20 не найдена — может жить в других чанках.
- DeepSeek: есть ли шеринг диалогов и запуск HTML в потребительском чате.
- Manus: пошаговый «replay» общей задачи — только сторонние описания.
- Kimi: изоляция `ok.kimi.link`, роли при шеринге дизайна.
- Ни у одного продукта не нашёл документированного присутствия (курсоры, «кто сейчас правит») на артефакте.
