## Как собрано

- Шесть исследователей искали первоисточники: документацию, справку, журналы изменений, официальные блоги. Каждый факт снабжён ссылкой и, где известно, датой источника, а то, что не нашлось в первоисточнике, помечено «не подтверждено». Перед поиском каждый прочитал раздел «Артефакты» перечня [`2026-11-agent-features`](../2026-11-agent-features/README.md) и строки своих продуктов, чтобы не повторять, а проверять и углублять.
- Четыре читателя разобрали код `main` `b1349f3b` с номерами строк.
- Критик полноты сверил отчёты с запросом владельца и нашёл три пробела. По ним сделаны дополнительные разборы f1–f3.
- Черновик плана затем проверили три независимых критика: правила и безопасность, код, запрос и продукт. Их итог — план 88, §14.
- В запросах к внешним сервисам не было ни названия продукта, ни данных владельца.
- Копии страниц источников остались в сессии исследования и в репозиторий не входят.

## Главное

- Почти все продукты разводят рабочий объект и публикацию: Bolt — «two different things», Perplexity — «Publishing and visibility are separate», у ChatGPT — Space и Sites, у Copilot — Pages и отдельная публикация.
- Агенту лучше всего даётся точечная правка по id блока или по цитате с проверкой ревизии на сервере: Claude Docs `ifHash+ifRev`, Notion MCP — одно вхождение `old_str`, Canva MCP — транзакции, Amp — ревизии с применением совпадающих правок. CRDT для агентов не используют: сервер не может проверить правку до показа.
- Одновременную правку несколькими агентами системно не решил никто. Лучшие заготовки: условная запись, присутствие (Webflow Agent Presence), общая история версий с автором (Manus).
- Комментарий и выделение — главный способ показать агенту место. Делиться может только человек.
- Слова «артефакт» нет ни в одном русском продукте. Готовая русская модель доступа — Яндекс.
- В коде Радити уже есть почти всё для основы: живая запись документа с проверкой `core` раз в 1,5 с, правка по якорю и `expectedVersion` у страниц, сигналы PostgreSQL → `core` → Redis → SSE, показ HTML с непрозрачным источником через `/v/<token>`. Не хватает ревизии блока, доступа между пространствами и своего канала изменений у объекта.
- `glm-5.3` картинок не видит. На плане есть зрячая GLM-5.3-Flash, но путь к ней закрыт драйвером и политикой тела роли `llm` (f1).
- Готовых открытых эталонов под блоки с ревизиями нет, но строительные блоки со свободной лицензией есть для каждого вида (f2).
- Комментарии и совместная правка между людьми, вероятно, делают сервис организатором распространения информации — с журналом на 3 года, хранением сообщений на 6 месяцев и доступом для ФСБ (f3).

- Часть сведений о Qwen, Z.ai и Grok взята из строк интерфейса и флагов веб-конфигурации.
- Держит ли OpenCode 1.18.34 ресурсы MCP и подписки — не проверено, поэтому семейство в плане опирается только на `tools/call`.
- Включает ли журнал Traefik строку запроса до её отбрасывания — нужна проверка на стенде (влияет на запасной адрес ссылки `/a?k=…`).
- Принимает ли адрес плана Z.ai `image_url` у `glm-5.3-flash` и доносит ли OpenCode 1.18.34 картинку до модели — живой проверки не было (f1).
- Поведение рамки правки без скриптов в трёх движках браузеров и загрузка шрифтов в непрозрачной рамке — первые спайки плана (f2).
- Реестр ОРИ Роскомнадзора 19.11.2026 не открылся. Практика собрана по вторичным источникам, а есть ли в реестре Zoom, Discord, Slack, Notion и Miro, не проверено (f3).
