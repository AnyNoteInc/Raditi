# SEO-рекомендации для сайта мастерской «Пион»

## Главное

Сайт почти не виден в поиске по запросам «доставка цветов» и «букет на свадьбу»: у страниц нет описаний, а каталог закрыт от роботов.

## Что исправить

### 1. Открыть каталог роботам

Сейчас в `robots.txt`:

```text
User-agent: *
Disallow: /catalog/
```

Должно быть:

```text
User-agent: *
Disallow: /cart/
Sitemap: https://pion.example.ru/sitemap.xml
```

### 2. Заголовки и описания

У каждой страницы — свой `<title>` до 60 знаков и `<meta name="description">` до 160:

```html
<title>Букеты с доставкой по Москве — «Пион»</title>
<meta name="description" content="Свежие букеты за 2 часа. От 2 900 ₽. Фото букета перед отправкой.">
```

### 3. Скорость

- сжать фото каталога — сейчас 2–4⍽МБ на картинку;
- включить кеширование: `Cache-Control: max-age=31536000` для `/static/`.

## Ключевые запросы

| Запрос | Частота в месяц | Страница |
|:--|--:|:--|
| доставка цветов москва | 135⍽000 | главная |
| букет невесты | 22⍽000 | /svadby |
| пионы купить | 18⍽500 | /catalog/piony |

## Проверка

После правок — переобход в [Яндекс Вебмастере](https://webmaster.yandex.ru/) и проверка через 2 недели.
