# Сравнение CRM для салона

## Коротко

Для салона на 4 мастера подходит **YCLIENTS** или **Dikidi**: обе дают онлайн-запись, напоминания и учёт абонементов. Если нужна интеграция с сайтом через API — берите первую.

## Подробнее

### YCLIENTS

- Плюсы: зрелый продукт, много интеграций, *журнал записи* удобный.
- Минусы: дороже, часть функций — в старших тарифах.

### Dikidi

- Плюсы: бесплатный тариф для одного мастера.
- Минусы: нет API, выгрузка только в `.xlsx`.

### Битрикс24

- Плюсы: CRM «на всё», задачи, телефония.
- Минусы: для записи в салон — избыточно; настройка займёт ~2 недели.
