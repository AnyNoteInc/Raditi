# Технические требования к сайту онлайн-записи

## Окружение

- Хостинг — российский, ФЗ-152 (данные клиентов в России).
- Домен — `zapis.example.ru`, сертификат Let's Encrypt.
- Резервная копия — раз в сутки, хранить 14 дней.

## Форма записи

Поля и проверки:

| Поле | Обязательное | Проверка |
|:--|:-:|:--|
| Имя | да | 2–50 знаков |
| Телефон | да | `+7XXXXXXXXXX` |
| Услуга | да | из списка |
| Комментарий | нет | до 500 знаков |

Пример запроса к API:

```bash
curl -X POST https://zapis.example.ru/api/bookings \
  -H 'Content-Type: application/json' \
  -d '{"name": "Анна", "phone": "+79190000000", "service": "стрижка"}'
```

Ответ:

~~~json
{
  "id": "b_102",
  "status": "confirmed",
  "time": "2026-11-21T15:00:00+03:00"
}
~~~

## Уведомления

1. SMS клиенту — сразу после записи.
2. Напоминание — за 24 часа и за 2 часа.
3. Мастеру — в Telegram, через бота.
