# Возможности AI-агентов: ввод, вывод и остальное

Исследование 14.11.2026 по запросу владельца: «давай проведем анализ всех агентов, а также все их возможности, собери списком все известные по всем агентам фичи в воде и выводе, изучи openai, claude code, kimi и остальных других агентов openclaw и так далее, собери полный список функциональных возможностей».

Здесь единый перечень того, что умеют AI-агенты: что пользователь может подать на вход, что агент показывает и выдаёт и что он умеет помимо этого. Изучено 66 продуктов в 16 группах. Для каждой возможности указано, у кого она есть и есть ли она в чате Радити. Это перечень, а не план: решений и приоритетов здесь нет.

По темам:

- **Работа с агентом, пока он занят.** У других можно поставить сообщение в очередь (38 продуктов) и поправить эту очередь (32). Можно направить идущий ход (26), отправить сообщение с прерыванием (17) или задать боковой вопрос (15). В Радити, пока агент работает, поле закрыто, и вместо «Отправить» стоит «Остановить».
- **Голос.** Диктовка — самая распространённая возможность, которой в Радити нет (43 продукта). Дальше идут живой голосовой разговор (25) и режим «нажми и говори» (14).
- **Расширения.** Навыки (41), субагенты (31), навыки как команды (27), хуки (25), свои команды (19) и свои агенты (18), вход в MCP-серверы по OAuth (18), SDK (16). Плагины в Радити есть лишь частично (EX-04): по умолчанию агенту подключены серверы Context7 и Playwright, а раздел «Навыки агента» сделан, но в кабинет не встроен.
- **Каналы и фон.** Агент в рабочих чатах (32), настольное приложение (28), задачи по расписанию (26). Агент в личных мессенджерах (18; у Радити Telegram запланирован, P13). Системные уведомления о конце хода (22) и запуск по событию (16).
- **Список чатов.** Ветка разговора (27), поиск по чатам (25), архив (19), закрепление (17).
- **Контекст.** Упоминание файла (32) и папки (21) через @. Личные инструкции на все проекты (20; у Радити есть только «Подсказки агенту» одного проекта). Показ заполнения окна контекста (18).
- **Планы и разрешения.** Режимы разрешений (24), режим плана до правок (21), режим планирования (19). В Радити опасное держат инструкции хода и подтверждение `/release`; окна разрешения на действие нет (IU-03, частично).

Вторая сверка перевела 17 из 80 строк из «нет» в «частично», в «есть» — ни одной. Почти везде нашлась близкая замена, а не сама возможность:

- автопамять (CX-02, CX-07) заменяют «Подсказки агенту» проекта;
- перетаскивание файлов (IC-66) — вставка файла из буфера;
- откат к выбранному сообщению (IU-05) — `/undo` на один шаг;
- диаграммы Mermaid (OW-02), презентации (OR-72) и генеративный интерфейс (OR-77) — страница `.html` во вкладке «Документы»;
- агент в браузере пользователя (OO-07) — облачный браузер с «Взять управление».

## Как собрано

1. **Разметка.** 26 категорий: 8 для ввода, 10 для вывода и 8 для остальных возможностей (названия и состав — в начале каждого раздела `features.md`).
2. **Сбор.** По каждой из 16 групп отдельный исследователь читал документацию, журналы изменений и анонсы. Каждая строка записана со ссылкой на источник. Запросы поиска не называли ни Радити, ни владельца.
3. **Проверка.** Независимый проверяющий сверял строки группы с первоисточниками. Он помечал каждую строку как верную, неверную, устаревшую или неясную и добавлял пропущенное.
4. **Перечень Радити.** Отдельный разведчик собрал по коду и планам, что уже есть в чате Радити (`raditi.md`).
5. **Сведение.** По каждому из 11 разделов одинаковые по сути возможности разных продуктов сведены в одну строку. Различия записаны в «Различия», каждой строке выставлен статус Радити.
6. **Сверка Радити.** По каждому разделу строки «есть» и «частично», а также строки «нет», которые встречаются у трёх и больше продуктов, перепроверены по коду. Исправлено 52 статуса.
7. **Полнота.** Критик искал пропущенные возможности и продукты. Три исследователя добрали найденные пробелы (40 строк ➕).
8. **Вторая сверка.** 80 самых частых строк «нет» ещё раз проверены по коду: пять независимых проверяющих старались найти в коде хотя бы частичную реализацию. 17 строк переведены в «частично».

Всего в работе было 64 агента.

## Статусы Радити

- ✅ **есть** — клиент пользуется этим в чате так, как описано: по сути, не обязательно во всех вариантах;
- 🟡 **частично** — урезанный вид, только вне production, только у агента без показа клиенту или близкая по смыслу замена (она названа в строке);
- ❌ **нет** — в коде не найдено;
- — **неприменимо** — по смыслу не нужно сервису, где владелец сайта пишет в веб-чат: функции терминала и IDE, сами протоколы.

## Оговорки

- **Дата.** Продукты меняются еженедельно, перечень верен на 14.11.2026.
- **«У кого» — нижняя граница.** Группы изучены с разной глубиной. В кругах критика и добора у части агентов кончилась квота веб-поиска, а часть страниц OpenAI отвечала 403. Если продукта нет в списке, это не значит, что возможности у него нет.
- **Неподтверждённые строки.** 1 456 строк проверяющие по отдельности не разбирали. Возможности, которые держатся только на неподтверждённых строках, помечены ⚠ в `features.md`. В `products.md` у каждой строки своя пометка: ✓ — подтверждена, ? — под вопросом, + — добавлена проверяющим.
- **Повторы между разделами.** Разделы сводились независимо, поэтому близкие возможности иногда стоят в двух разделах. Например, задачи по расписанию — EX-80 и CH-09, режим плана — OW-114 и IU-75, картинки — OR-70 и TL-05.
- **Столбец «Радити» — по коду `main` 14.11.2026.** Перечень Радити собран на `ce947861`. Сверки шли, пока в `main` вливались #72–#75 (до `2e2ad5a4`). Поэтому #75 — «Опубликовать по ссылке» документа клиентом — учтён не везде: строки публикации (например, OR-91) стоит перечитать.
- **«Неприменимо» — суждение, а не факт.** Его стоит пересмотреть, если появятся каналы кроме веба: Telegram, телефон, настольное приложение.
